# 🎓 Quizzy Class – Cartoon Quiz Game

A funny, casual **2D cartoon quiz game** with expressive characters, trick questions, combos, power-ups, and classroom-style progression.

🔗 **Play now:** [https://crosswordmaster.ai.studio](https://crosswordmaster.ai.studio)

---

## 📖 About

Quizzy Class turns quizzing into a playful classroom adventure. Answer questions, watch the cartoon characters react, beware of trick questions, and climb your way up through the class.

## ✨ Features

- 🎨 **Casual 2D cartoon style** – bright, fun visuals
- 😜 **Expressive characters** – they react to your answers
- 🧠 **Trick questions** – not everything is as it seems!
- 🔥 **Combos** – chain correct answers for bonus points
- ⚡ **Power-ups** – get help when a question gets tough
- 🏫 **Classroom progression** – level up as you play

## 🎮 How to Play

1. Open the game link in your browser (desktop or mobile).
2. Start a quiz and read each question carefully.
3. Pick the correct answer – watch out for tricky wording.
4. Build combos with consecutive correct answers.
5. Use power-ups wisely to survive hard questions.
6. Progress through the classroom and beat your best score.

## 🛠️ Tech

- Runs directly in the browser – no installation needed
- Responsive layout for desktop and mobile
- Built with [Google AI Studio](https://aistudio.google.com)

## 🚀 Run Locally

```bash
# Clone the repository
git clone <your-repo-url>
cd <your-repo-folder>

# Install dependencies
npm install

# Start the dev server
npm run dev
```
